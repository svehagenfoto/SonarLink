About SonarLink

SonarLink is a fan made companion tool for Subnautica 2. It installs the required bridge mod, opens an in game style menu, and adds features like third person camera.

Disclaimer: Not affiliated with Unknown Worlds Entertainment. Subnautica 2 is a trademark of Unknown Worlds Entertainment.
